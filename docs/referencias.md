# Referencias

Material de consulta que se usó durante el diseño. No se redistribuye aquí
(son publicaciones de terceros); se dejan las citas para poder localizarlas.

- Anwar, Favier y Vida, *Design and Implementation of a Microcontroller-Based
  Ignition System*, The Technology Interface, otoño de 2007.
- M. S. Ajmir et al., *Automated Spark Ignition Timing Controller (ASITC) for
  Internal Combustion Engine Control Unit*, IOP Conf. Ser.: Mater. Sci. Eng.
  501 012012, 2019.
- Per Hillerborg, *Dynamic Model of a Diesel Engine for Diagnosis and
  Balancing*, Master's Degree Project, KTH.
- Maplesoft, *Mean-Value Internal Combustion Engine Model with MapleSim*.

Proyectos de código abierto que se consultaron o se usaron como herramienta:

- [speeduino](https://github.com/noisymime/speeduino) — ECU de código abierto.
- [buck50](https://github.com/thanks4opensource/buck50) — analizador lógico y
  generador de señales sobre STM32F103 ("Blue Pill").
- [logic-analyzer](https://github.com/aster94/logic-analyzer) de Vincenzo — el
  que de verdad se usó; la versión modificada está en
  [`tools/analizador-logico/`](../tools/analizador-logico/).
